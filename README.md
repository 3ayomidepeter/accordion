# FAQ ACCORDION IMPLEMENTATION

This project is a simple FAQ accordion built with HTML, CSS and JAVASCRIPT. It provides an interactive section for user to toggle an a FAQ for answers by clicking associated buttons https://roadmap.sh/projects/accordion

# FEATURES

- Interactive FAQ sections.
- Answers are hidden by default and toggle visibility when a question is clicked.
- Clean and responsive design.

# TECHNOLOGIES USED

1. HTML - Structure of the FAQ page.
2. CSS - Styling and layout of the FAQ sections.
3. JavaScript - Functionality for toggling FAQ sections.

# SETUP INSTRUCTIONS

1. Clone or download the repository.
2. Open the `index.html` file in a browser to view the project.

# CODE EXPLANATION

## HTML

The HTML structure consists of:

- A `header` for the title and description of the FAQ.
- Multiple `section` elements, each representing a question and its answer.

## CSS

The CSS provides:

- Styling for sections.
- Hidden answers by default with `display: none`.

## JavaScript

The JavaScript toggles the `display` property of each answer when the associated button is clicked.
